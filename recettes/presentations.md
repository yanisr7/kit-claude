# Recette — Présentations, decks, factures, documents

## Deck / présentation client
- **PowerPoint (.pptx)** : *« fais-moi un deck de 10 slides pour présenter [projet] à [client], couleurs orange/noir »* → skill `document-skills:pptx`.
- **Page web de présentation** (plus impactant, se partage par lien) : Claude crée une page (Astro, HTML) déployée sur Vercel → *« fais une page de présentation pour la collab X × Y, avec les chiffres, les photos, le planning »*.
- Toujours donner : le **client**, l'**objectif** (vendre ? informer ?), les **données réelles** (chiffres, abonnés, dates), les **visuels**.
- Ne jamais laisser Claude **inventer des chiffres** : s'il manque une donnée, il doit la demander.

## PDF, Word, Excel
- `document-skills:pdf`, `docx`, `xlsx` : lire, remplir, créer.
- Factures : partir d'une **ancienne facture** comme modèle (*« prépare la facture de ce mois en t'inspirant de celle-ci »*). Les infos légales (SIREN, TVA, IBAN) viennent **de toi**, jamais inventées.

## Marketing
- Plugin `marketing-skills` : copywriting, SEO, emails, landing pages, idées de contenu. Ex. : *« écris 3 versions de texte pour le teaser Instagram de la nouvelle veste »*.
